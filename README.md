# 雀帳（JANCHO）— 麻雀収支管理PWA

仲間内のセット麻雀やフリーの成績を記録・分析するための、1ファイル完結のWebアプリです。
スマホのホーム画面に追加して、アプリのように使えます（PWA）。

## できること

- 会（セット/フリー）を作成し、半荘ごとに **素点** または **スコア** で入力。素点は**100点単位**で入力（下2桁の「00」は固定表示、例：30500点 →「305」と入力）
- スコア計算は既定で **五捨六入**：2位以下の素点の100点の位を五捨六入し、丸めで生じた差分はトップが引き受け（例：10-30・25000持ち30000返しで素点9700/30500/3000/56800 → −30/+10/−57/+77）。端数処理は会ごとに変更可
- ルール設定：持ち点・返し・ウマ（5-10/10-20/10-30/20-30/カスタム等）・端数処理（五捨六入など）・レート・チップ・ゲーム代・**ヤキトリ・トビ賞**。会ごとに変更でき、変更すると半荘は自動再計算
- **ヤキトリ**：半荘入力の「ヤ」チェックで記録。ヤキトリの人が▲、トップが受け取り（初期▲10）
- **トビ賞（トバシ）**：飛びを検出すると「トバシた人」を選択でき、飛んだ人が▲、トバシた人が受け取り（初期▲10）。ヤキトリ率もホーム・ランキングに表示
- **座席・起家の記録**：東南西北の席割りを毎半荘記録。「起家を回す」ボタンで自動ローテーション（4人3麻の抜け番も自動循環）
- チップ精算、収支（スコア×レート＋チップ−ゲーム代）
- ホーム：収支・平均着順・連対率・着順分布・飛び率など
- 履歴：会の一覧、全件集計・複数会の合算集計（ベンチマークアプリと同じ縦持ち表）。集計表はスマホの画面幅に収まるよう4人分を等幅で表示し、収まらない場合は文字を自動で少し縮小（横スクロールなし。v1.4〜）
- 分析：プレイヤーランキング（9指標）、**席・起家別成績**、相手別成績（同卓時の自分の成績＋上家/対面/下家の位置関係別）、累積収支/スコアの推移グラフ
- データのJSON/CSVエクスポート・インポート、全削除

## 使い方（ホーム画面に追加するまで）

いちばん簡単なのは **Netlify Drop**（無料・登録は任意）です。

1. https://app.netlify.com/drop をPCまたはスマホのブラウザで開く
2. このフォルダ（index.html などが入ったフォルダ、または jancho-pwa.zip）をドラッグ＆ドロップ
3. 発行された `https://〜.netlify.app` のURLをスマホで開く
4. iPhone：Safariの共有ボタン →「ホーム画面に追加」
   Android：Chromeのメニュー →「アプリをインストール」

GitHub Pagesでも可：リポジトリにファイル一式を置き、Settings → Pages で公開するだけです。

ローカルで試すには：このフォルダで `python3 -m http.server` を実行し、`http://localhost:8000` を開きます（Service Workerはlocalhost/httpsでのみ有効）。

## データについて

- データは **端末のブラウザ内（localStorage）** にのみ保存されます。サーバーには何も送信されません。
- 機種変更やブラウザのデータ削除に備え、設定タブの **JSONエクスポート** で定期的にバックアップしてください。
- claude.ai のプレビュー（アーティファクト）で開いた場合は、アーティファクトの保存領域に自動で切り替わります。
- レートの初期値は **スコア1pt=200P／チップ1枚=1000P**（スクリーンショットの数値から逆算した推定値）です。**ヤキトリ▲10・トビ賞▲10・端数処理＝五捨六入** が初期値です。いずれも設定タブの「既定ルール」や会ごとのルール編集で変更できます（0で無効）。ゲーム代の初期値は0です。

## ファイル構成

- `index.html` — アプリ本体（HTML/CSS/JSすべて込み）
- `sw.js` — オフライン用Service Worker
- `manifest.webmanifest` — PWA設定
- `icon-192.png` / `icon-512.png` — アプリアイコン
